# kLab Tech Upskills

Tech Upskill Program at kLab.

## Project Setup

1. Clone the repository.

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file and add your MongoDB connection:

   ```env
   PORT=5000
   MONGO_URI=your_mongodb_connection_string
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the API:
   `http://localhost:5000`

6. Open Swagger documentation:
   `http://localhost:5000/api-docs`

## Technologies

* Node.js
* Express.js
* TypeScript
* MongoDB
* Mongoose
* Swagger
